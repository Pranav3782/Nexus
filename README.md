# Nexus

A polished, motion-led website for an independent digital studio. Built with React, Vite, Tailwind CSS, and Framer Motion.

- Live site: https://nexus-agency-pranav.netlify.app
- Repository: https://github.com/Pranav3782/Nexus

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS 3
- Framer Motion
- Lucide React

## Local Development

```bash
npm install
npm run dev
```

The development server runs at `http://localhost:5173`.

## Production Build

```bash
npm run build
npm run preview
```

The production bundle is generated in `dist/`.

## Deployment

The project is configured for Netlify with `netlify.toml`:

- Build command: `npm run build`
- Publish directory: `dist`
- Node version: 22

The contact form opens the visitor's email client with a pre-filled project brief. Replace placeholder contact details, testimonials, concept projects, and statistics before launch.
